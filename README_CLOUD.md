# Binance TR v20 Cloud Mobile

iPhone'da bilgisayardan bağımsız çalışacak şekilde hazırlanmış Streamlit sürümü.

## Deploy
- GitHub repository'ye yükleyin.
- Streamlit Community Cloud'da `app.py` dosyasını deploy edin.
- Oluşan URL'yi iPhone Safari'de açın.
- Safari > Paylaş > Ana Ekrana Ekle.

Bu uygulama gerçek emir göndermez; yalnızca piyasa verisi ve teknik analiz kullanır.
